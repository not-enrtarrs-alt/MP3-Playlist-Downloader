## Known limitations

No real playlist/network authentication smoke test or visible Windows-desktop test was performed. Cancellation discards a result after an underlying yt-dlp request returns; it cannot immediately interrupt that request. Folder scans, extra-file dialogs, downloads and tagging are M2; equalization and settings UI are M3; queue persistence and album retagging are M4. Album-sync state is displayed but not actionable yet. Track download/equalize/delete controls remain disabled. mp3gain is absent and proposed CLI flags remain unverified.
