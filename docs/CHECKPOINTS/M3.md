## Tests and acceptance evidence

- `.venv\Scripts\python.exe -m pytest -q`: **143 passed**, fully offline with fake mp3gain, yt-dlp, network, and Recycle Bin.
- Discovery precedence, `/r /k /s s` argument construction, timeout, nonzero exit, output truncation, missing binary, and no equalized flag on failure were tested with fakes. Selected equalization continues after per-file failures and cancellation waits for the current file; automatic equalization preserves downloads on failure.
- pytest-qt verifies settings round-trip, validation, cookie basename privacy, explicit diagnostics, toolbar enablement, worker-thread equalization, and close/cancel. A startup initialization race found during acceptance was fixed and regression-tested.
- `demo --check` and isolated `doctor --json` returned 0; doctor reports missing mp3gain as a warning. Both read-only reference hashes match the initial baseline.

## Known limitations

No real YouTube download, cookies, Windows Recycle Bin, or visible-desktop smoke test was performed. M4 must implement overwrite, manual linking, album retag UI, rate-limit countdown and bounded auto-resume; the auto-resume setting is currently only stored. Installer is M5.
