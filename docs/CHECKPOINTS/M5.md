## Tests and acceptance evidence

- Offline `scripts/build.ps1` with `PIP_NO_INDEX=1` reused installed dependencies, ran **189 passing tests**, and produced `dist/MP3 Playlist Downloader/` as a windowed PyInstaller onedir. Earlier onedir builds were preserved separately.
- The final frozen GUI opened a Windows main window, created its isolated database, and closed with exit 0. Frozen `version`, `doctor --json` and `demo --check` each exited 0. The source demo reported 2 green, 1 blue, 1 red and 1 yellow; the demo also works with ffmpeg absent.
- Source `doctor --json` exited 0, reported ffmpeg/ffprobe versions and warned that mp3gain and cookies were absent. Diagnostic output redaction is covered by offline tests.
- Both read-only reference hashes match the initial baseline. No ffmpeg or mp3gain binary was bundled or committed.

## Known limitations

Inno Setup `ISCC.exe` was unavailable, so `scripts/installer.iss` was not compiled or installed. The per-user uninstall/data-preservation behavior is specified and statically tested, but still requires real installer verification. Real YouTube downloads/cookies, real mp3gain flags/audio effects, and real Recycle Bin operations have not been tested. PyInstaller reported missing optional Qt SQL-driver and optional yt-dlp dependencies; the app uses Python sqlite3, and real YouTube behavior remains unverified. See `docs/SPEC.md` and `docs/HANDOFF.md` for remaining limitations.
