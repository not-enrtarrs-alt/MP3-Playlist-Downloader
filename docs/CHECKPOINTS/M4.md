## Tests and acceptance evidence

- `.venv\Scripts\python.exe -m pytest -q`: **177 passed** offline with fake yt-dlp, network, mp3gain, and Recycle Bin.
- A Qt worker integration test exercises the initial rate limit plus three failed automatic retries, then verifies manual resume resets the streak. Startup does not auto-resume, dismissal cancels the timer, and pending rows persist.
- Overwrite tests verify confirmation, restart persistence, old-file recycling only after a new MP3 is ready, recycling failure, file-change detection and collision safety. Re-download resets attempts.
- Linking tests verify external source copies are unchanged, local extras are adopted, other tracked files and hard links are protected, replacements are recycled, and auto-equalization failures leave a warning. Album tests verify `TALB` updates preserve other frames and partial failures retain the pending flag.
- `demo --check` and isolated `doctor --json` returned 0. Both read-only reference hashes match the initial baseline.

## Known limitations

Real YouTube downloads, cookie authentication, mp3gain, Windows Recycle Bin and visible-desktop behavior were not tested. mp3gain `/?` flags remain unverified because the binary is absent. An explicitly adopted extra is tagged in place before an old-file recycle attempt, so its tags may change even if recycling fails; the old tracked file and DB state stay unchanged. Installer and complete documentation are M5; demo equalization states are simulated.
